# AI Agent 研发工程师（实习/校招）

## 职位描述

我们团队致力于构建下一代智能 Agent 系统，通过多 Agent 协作、强化学习、LLM 工程化等技术，打造能够自主规划、执行复杂任务的智能体平台。

### 核心职责
1. 参与多 Agent 系统架构设计与开发，实现 Agent 间的协作、通信与任务分配
2. 运用 LangChain、LlamaIndex 等框架，构建基于 LLM 的应用系统
3. 设计并实现 Agent 的记忆系统、工具调用接口与决策逻辑
4. 应用强化学习、因果推断等技术优化 Agent 的决策能力
5. 参与 Agent 系统的工程化部署，包括 API 设计、性能优化与监控

## 职位要求

### 基本要求
1. 2025-2027届本科及以上学历在读，计算机、人工智能、软件工程相关专业
2. 扎实的编程能力，熟悉 Python，了解 C++/Go 者优先
3. 熟悉数据结构与算法，具备优秀的工程实现能力

### 技术栈要求
1. 熟悉 LLM 应用开发，了解 Prompt Engineering、RAG、Function Calling 等技术
2. 了解 LangChain、LlamaIndex、AutoGPT 等 Agent 框架
3. 了解强化学习基础概念（MDP、Q-Learning、PPO 等）
4. 熟悉 FastAPI/Flask 等 Web 框架，了解微服务架构
5. 了解向量数据库（FAISS、Milvus、Pinecone 等）

### 加分项
1. 有 Agent 项目实战经验（GitHub 可展示）
2. 熟悉 MCP（Model Context Protocol）协议
3. 了解多 Agent 协作算法（拍卖、共识、博弈等）
4. 有开源项目贡献经历

## 工作方式
- 混合办公，每周至少 3 天 onsite
- 实习期 3-6 个月，表现优秀可转正

- 转正后：行业 TOP 薪资 + 期权
